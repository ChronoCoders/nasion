# Nasion

A reference bench for brain signal software. Nasion runs an EEG analysis tool on open recordings, runs the same analysis on control inputs, and writes both results into one signed record that anyone can re-run.

Nasion is a research tool for testing EEG analysis software. It is not intended to diagnose or treat any condition, and every claim states its measured accuracy, data and date.

Status: not released. The `site/` folder holds a preview page.
